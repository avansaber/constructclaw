# ConstructClaw

Construction project management for [ERPClaw](https://github.com/avansaber/erpclaw). Job costing, estimating, subcontractor management, AIA billing, daily field reports, change orders, RFIs, submittals, safety compliance, and earned value management. <!-- SYNC:value:module.constructclaw.actions -->160<!-- /SYNC --> actions across 10 domains.

## Features

- **Job Costing** -- cost codes (WBS), cost entries, commitments, budget vs actual tracking, WIP reports
- **Estimating & Bids** -- estimates with line items, bid tracking, bid comparison, award workflow
- **Subcontractors** -- subcontracts, pay applications, lien waivers, aging reports
- **AIA Billing** -- schedule of values (G702/G703), progress bills, retention tracking and release
- **Daily Reports** -- field reports, labor logs, material tracking
- **Change Orders** -- PCOs (potential) to CCOs (contract) with auto-creation on approval
- **RFIs & Submittals** -- request for information and submittal tracking
- **Safety** -- incident reports, toolbox talks, safety certifications, OSHA 300 log
- **Project Controls** -- earned value (CPI, SPI, EAC, TCPI), project status reports
- **Reports** -- job profitability, cost summary, billing summary, subcontractor aging

## Installation

Requires [ERPClaw](https://github.com/avansaber/erpclaw) core.

```
install-module constructclaw
```

## Quick Start

```
"I run a construction company -- set me up"
```

The bot will install ConstructClaw and guide you through creating jobs, setting up cost codes, managing subcontracts, and tracking progress billing.
